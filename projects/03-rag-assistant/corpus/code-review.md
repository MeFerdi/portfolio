# Code Review Guidelines

Owner: Engineering.

## Approvals

Changes to production services need approval from two reviewers, at least one of whom is a code owner. Changes to internal tools need one approval.

## Pull request size

Keep pull requests under 400 changed lines where possible. Larger changes should be split or reviewed in a scheduled walkthrough.

## Before merging

All CI checks must pass before merging. Reviewers should respond to a review request within one business day.

## Database migrations

Pull requests containing database migrations must be reviewed by a member of the data platform team.
