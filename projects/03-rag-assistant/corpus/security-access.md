# Security and Access Policy

Owner: Security team.

## Accounts and passwords

Multi-factor authentication (MFA) is mandatory for every company account. Use the company-provided password manager for all work credentials; never reuse a work password anywhere else.

## Devices

Company laptops must have full-disk encryption enabled and screen lock set to 5 minutes or less. Personal devices may access email and chat only through the managed mobile app.

## Lost or stolen devices

Report a lost or stolen device to the Security team within 1 hour by posting in the #sec-incidents channel or calling the security hotline. The device will be remotely wiped.

## Access reviews

Managers review their team's access to production systems every quarter. Access that is not re-approved during the review is removed automatically.
